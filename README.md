# Bike-Sales-Analysis-Excel-Project

This project is an end-to-end Excel data analysis project based on bike sales data. It covers data cleaning, data transformation, exploratory data analysis (EDA), pivot table creation, KPI calculation, and dashboard development to generate meaningful business insights. [file:3]

## Project Objective

The main objective of this project is to analyze customer and sales-related data to identify patterns in bike purchases and understand how demographic and lifestyle factors influence buying behavior. [file:3]

## Dataset Features

The dataset includes customer-related fields such as:

- ID
- Marital Status
- Gender
- Income
- Children
- Education
- Occupation
- Home Owner
- Cars
- Commute Distance
- Region
- Age
- Purchased Bike [file:3]

Additional derived columns were also created during preprocessing, such as:

- Age Bracket
- Income Bracket [file:3]

## Steps Performed

### 1. Data Cleaning
- Checked the dataset for inconsistencies and formatting issues.
- Converted income values into proper numeric format.
- Standardized categorical values for analysis.
- Created new columns such as Age Bracket and Income Bracket for better segmentation. [file:3]

### 2. Exploratory Data Analysis
- Analyzed bike purchases based on gender, marital status, age bracket, region, occupation, education, and commute distance.
- Used summary statistics and formulas to calculate important metrics.
- Identified customer behavior patterns and segment-wise trends. [file:3]

### 3. Pivot Tables and KPIs
- Built pivot tables to summarize customer purchase behavior.
- Calculated key metrics such as total buyers, average income, and percentage-based insights.
- Compared bike purchases across different demographic groups. [file:3]

### 4. Dashboard Creation
- Designed an interactive Excel dashboard to present the analysis visually.
- Added charts and filters to improve data interpretation.
- Created a clean layout for better reporting and presentation. [file:3]
